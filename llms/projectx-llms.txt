# ProjectX (Infinity / InfinityOS)

> ProjectX is a San Francisco-based Y Combinator (Spring 2026) startup building Infinity, a cloud operating system for AI agents. Infinity lets agents and humans orchestrate GPU workloads through a chat interface rather than traditional APIs, running multiple Windows and Linux applications (Blender, VS Code, DaVinci Resolve, Unreal Engine, Isaac Sim) simultaneously — each on independent compute and GPU inside one shared browser workspace with sub-minute cold starts. A public API, developer docs, status page, changelog, and blog are announced as "coming soon"; no programmatic API surface is published yet.
